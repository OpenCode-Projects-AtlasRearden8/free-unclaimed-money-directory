# STATUS.md — Free Unclaimed Money Directory

## What was built

A static, offline, single-file website (`index.html`) that catalogs **official, free finders for money you may already own**, as card tiles driven entirely by `data/finders.json`:

- **15 finder cards** across 7 filterable categories: state unclaimed property (NAUPA map, MissingMoney.com, plus Indiana, California, Texas, New York, Florida portals), federal pensions (PBGC Missing Participants, DOL abandoned plans), bank/credit union (FDIC, NCUA), insurance (NAIC Life Insurance Policy Locator), tax refunds (IRS), savings bonds (Treasury Hunt), and other federal refunds (HUD/FHA).
- Each card shows: operator (official agency), what it finds, **documents to have ready**, practical tips, and a link to the official source only — every card carries a permanent **"never pay a finder for this"** notice.
- Site-wide scam-warning section (6 rules, collapsible) with the loud **never-pay-a-finder** headline; a "documents to gather before you start" section; live text search; category filter buttons; result count; print stylesheet; accessibility features (labels, aria-pressed, focus rings, live region).
- Explicit disclaimer banner: information only, never financial advice.
- Zero external requests: no fonts, no scripts, no images, no CDN — opens fully offline from disk. No ads, no affiliate links.
- Support files: `data/finders.json` (data), `schema/finders.schema.json` (JSON Schema, draft 2020-12 subset), `src/template.html` + `src/build.js` (injection build), `tests/run-tests.js` (19 tests), `README.md` (maintenance guide), `LICENSE` (MIT, Copyright (c) 2026 Asdale Dynamics, LLC).

## How to run it

- **Use:** open `index.html` directly in any browser (double-click; works offline, e.g. from a USB drive). No install, no server.
- **Rebuild after editing data/template:** `node src/build.js` → regenerates `index.html`.
- **Run tests:** `node tests/run-tests.js` (needs Node only; no npm packages).

## Known gaps

- **Link rot is structural:** the test suite checks URL *shape*, not reachability (tests must stay offline). Manual re-check of all 15 links every few months is required; README documents the procedure.
- **One domain shape to monitor:** `https://www.treasurydirect.gov/savings-bonds/treasury-hunt/` matches the schema's `https://` rule but has no deep link verification; if Treasury reorganizes, fall back to `https://www.treasurydirect.gov` search.
- **Coverage, not exhaustiveness:** 15 cards deliberately favor big/stable official programs. Missing-but-candidate sources (state-by-state remaining ~44 state portals, VA life insurance, SEC/EDGAR, state DOR refund pages) are easy schema-compliant additions; add to `data/finders.json` and rebuild.
- **No-JS experience:** with JavaScript disabled the cards don't render; a notice points to the JSON/README which contain the same info. A fully static fallback list could be generated by the build script if wanted.
- **No automated browser/E2E test:** rendering is tested in a DOM-less sandbox (pure functions), not in a real browser; a `node --test`-style migration could come later, and a `package.json` with a `test` script could be added without changing behavior.
- English-only; no site search analytics by design (privacy-first).
